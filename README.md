# Patisserie Landing Page
<img width="1900" height="3578" alt="Full-page preview of the Patisserie landing page" src="https://github.com/user-attachments/assets/71014d9d-343d-4c7f-9b78-ec0ccb9d82f7" />

A responsive, accessible landing page concept for a bakery & patisserie shop, built from scratch with vanilla HTML, CSS and JavaScript.

### Live Demo : 
[db-douae.github.io/landing](https://db-douae.github.io/landing/)

### Highlights
* Fully responsive (desktop, tablet, mobile) with a mobile navigation menu
* Scroll-reveal animations, disabled for users who prefer reduced motion
* Images optimized to WebP: **11 MB** to **~370 KB**
* Lighthouse (mobile): Performance 95, Accessibility 98, Best Practices 100, SEO 100
<img width="1920" height="937" alt="Lighthouse report: Performance 95, Accessibility 98, Best Practices 100, SEO 100" src="https://github.com/user-attachments/assets/03dc95a8-20ea-4e32-a822-d49ed88bbe1e" />

### Technologies used:
* HTML
* CSS 
* JavaScript
* [Typed.js](https://github.com/mattboldt/typed.js)
* [Font Awesome](https://fontawesome.com/)
* Google Fonts (Lora, Sacramento)
